# SPEC v7.3 — 评论页融合背景 / 迷你播放器手势 / 纯白主题 / 风格统一

状态：实现冻结。级别 L2。基线：`80c8304`（v0.7.2）。目标：versionCode 11 / 0.7.3。

## 需求
1. 播放页评论页背景与播放器渐变融合（不再是纯白卡片）。
2. 全局迷你播放器：去掉最右侧「播放队列」按钮；支持左滑下一首、右滑上一首。
3. 新增全局「纯白」主题（整体更纯净）。
4. 检查全局页面，统一设计风格（顺带修可见的排版/主题问题）。

## 实现
- `CommentsPage`：去掉白色圆角卡片；非纯白播放页用「轻微压暗渐变 + 嵌套 SaltTheme（白字、白 8% 卡片、白描边）」渲染评论；纯白播放页用主题深色文字。
- `BottomPlayerBar`：删除队列按钮与参数；`pointerInput + detectHorizontalDragGestures` 累计水平位移，超过 56dp 触发上一首/下一首；点按整条仍是进入播放页。
- `ThemeMode` 新增 `PURE_WHITE("纯白")`；`MainActivity` 把纯白主题传入 `BbTheme(pureWhite=true)` 使用既有纯白调色板；纯白主题下设置页隐藏动态取色/强调色；播放页徽章、歌词、评论文字随纯白背景切换深色。
- `SettingsScreen`：新增 `SettingNoteRow`（长说明行），修复「凭据安全」标题被挤成竖排。
