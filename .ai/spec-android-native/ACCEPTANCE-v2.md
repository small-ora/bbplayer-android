## 4. 已知限制 / 需要你裁定

1. **逐字歌词数据源**：解析与 UI 已就绪，但匿名接口拿不到逐字轨（见 G1）。若验收要求线上歌曲必须逐字，需要追加「QQ QRC 解密（3DES+zlib）」或「网易 eapi」子任务（会引入加密实现，建议单独评审）。
2. **备份恢复设置**：设置文件随备份恢复，但需重启应用生效（DataStore 运行态）。
3. **导出容器**：下载缓存是 B 站 `m4s`（ISOBMFF），导出命名 `.m4a`，不写入 ID3/封面等元数据（上游用 jaudiotagger，本期未引入）。
4. **通知栏歌词**：实现为媒体通知第二行（替换 artist 行），部分 OEM 折叠态仅显示标题；未做第三方状态栏歌词模块（SuperLyric/Lyricon/魅族）。
5. **导入耗时**：700ms/曲限速，100 首约 2 分钟，进度可见；第三方接口为非公开接口，存在失效风险。
6. **平板/横屏**：按你的要求不做验收（代码保留，不影响手机）。
7. **未做（仍属登录派生或外部依赖）**：登录/收藏夹/合集/UP 主/稍后再看/同步、B 站装扮皮肤、车载歌词、音频频谱、响度均衡、付费音质。

## 5. 需要你验收的 3 件事（≤10 分钟）

1. 打开「我的→已下载」：播放一首已下载歌曲，开飞行模式确认真能出声；再试「导出」看 Music/BBPlayer 下文件。
2. 打开「我的→收听排行 / 播放历史 / 导入歌单（粘贴网易云歌单链接）/ 播放页→查看评论」，确认数据与交互正常。
3. 设置里切「纯白 / 强调色 / 播放器背景 / 迷你样式」与「桌面歌词」，判断椒盐风格是否继续成立；桌面歌词需授悬浮窗权限。
