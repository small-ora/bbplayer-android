# SPEC v2 — 非登录功能补齐（BBPlayer 安卓原生版）

状态：实现期冻结（用户指令：除登录相关外，其余上游功能都要做）。级别：L3（大范围新功能，无鉴权红线）。
基线：`c0fbd1c`（v1 冻结 SPEC）→ 本期分支 `feat/v2-non-login`，完成后合入 `main` 并发布 `v0.2.0`。

## 1. 目标
把上游 BBPlayer 中**不依赖登录**的能力补齐：下载/离线、外部歌单导入、评论、搜索建议/热搜、排行榜与历史、播放器与外观设置、歌词增强（逐字/逐曲偏移/桌面歌词/分享）、平板适配、更新检查与本地备份。

## 2. 明确不做（登录派生或外部依赖）
账号登录/扫码/Cookie、收藏夹、合集/系列、UP 主主页与关注、稍后再看、B 站播放历史上报、云同步/共享歌单、B 站装扮皮肤商城（改用本地主题预设）、SuperLyric/Lyricon/魅族状态栏歌词后端（第三方模块）、车载歌词（Android Auto）、音频频谱（需 RECORD_AUDIO）、响度均衡（匿名 playurl 无 loudness 数据）、付费音质档。

## 3. 可验证验收标准（AC）

### A. 工程与发布
- A1 `./gradlew :app:assembleDebug :app:assembleRelease` exit 0；全部单测（v1 166 + v2 新增 ≥ 45）0 失败。
- A2 真机安装运行，无 FATAL/ANR；关键新页面可达。
- A3 GitHub Actions 绿；tag `v0.2.0` 自动发布 Release（debug + release APK）。

### B. 本地库增强
- B1 当前播放队列可「保存为歌单」。
- B2 歌单内歌曲可上移/下移/置顶（顺序持久化）。
- B3 歌单内支持关键字过滤（本地即时过滤）。
- B4 本地备份：导出 zip（歌单/收藏/历史/续播/设置/歌词缓存），可从 zip 恢复并提示恢复数量。

### C. 下载与离线
- C1 播放页/列表可「下载」当前曲目；下载管理页显示 进行中/已完成/失败，含进度与大小。
- C2 支持取消/删除/清空已完成；下载并发数可在设置调整（1–3）。
- C3 已下载曲目播放**不发起网络流解析**（离线可播）；无网络时仍可播放已下载曲目。
- C4 已下载曲目可「导出到公共目录」Music/BBPlayer（可附带同名 .lrc），导出成功有路径提示。

### D. 发现与统计
- D1 搜索页输入时展示联想建议（≥3 条，点击填入/搜索）。
- D2 搜索空态展示 B 站热搜词（可点击搜索）。
- D3 「排行榜」页：B 站音乐区热门 + 我的收听排行（按播放次数/时长）。
- D4 「历史」页：按日分组展示，显示每日时长；可清空历史。

### E. 评论
- E1 播放页菜单可进入评论页：一级评论分页加载（≥20 条/页，含头像/昵称/内容/点赞数/时间）。
- E2 可展开查看楼中楼回复（≥2 条）并分页。
- E3 网络失败显示错误与重试，不崩溃。

### F. 播放器与外观
- F1 设置-外观：播放器背景样式（封面渐变/纯色/纯白）、迷你播放器样式（底部停靠/悬浮胶囊）。
- F2 纯白模式下界面为白底黑字，播放器背景不取色。
- F3 强调色预设（≥5 套）可切换并持久化（关闭动态取色时生效）。
- F4 迷你播放器「悬浮胶囊」样式生效（不遮挡底部内容、可点击进播放器）。

### G. 歌词增强
- G1 逐字高亮：增强 LRC 带词级时间时按词渐变高亮；设置可关；无词级时回退逐行。
- G2 逐曲偏移：每首歌词偏移独立保存（切换歌曲后恢复该曲偏移）。
- G3 歌词样式：现代（左对齐）/经典（居中）切换；翻译显示开关。
- G4 桌面歌词悬浮窗：开关+悬浮权限申请；显示当前行+翻译，可拖动、锁定、调字号/颜色，暂停时保留；关闭后移除。
- G5 通知/状态栏歌词：媒体通知第二行显示当前歌词行（设置可关）。
- G6 歌词分享卡片：生成图片（曲名/歌手/当前歌词/封面），可保存到相册或分享。
- G7 SPL 格式歌词可解析（与 LRC 并存），单测覆盖。

### H. 外部歌单导入
- H1 粘贴网易云/QQ 音乐歌单链接或 ID，解析出歌单名/封面/曲目数。
- H2 逐曲匹配 B 站视频（限速），展示匹配结果（成功/失败/时长差），失败项可手动搜索替换。
- H3 保存为本地歌单；导入过程显示进度。

### I. 适配
- I1 宽屏（≥600dp）底部 dock 改为左侧 NavigationRail，内容区不被遮挡。
- I2 横屏/平板下播放器与列表布局不重叠。

### J. 更新检查与关于
- J1 设置-关于：显示版本、检查更新（GitHub Releases），有新版提示并可打开下载页。
- J2 关于页列出开源许可（自身 MIT / SaltUI Apache-2.0 / BBPlayer MIT 参考）。

### K. 质量
- K1 新增单测覆盖：外部歌单解析、匹配评分、评论映射、下载索引/文件名、备份 zip、逐字歌词/SPL、强调色映射、历史按日聚合。
- K2 真机走查：下载→飞行模式播放；评论页；导入页；桌面歌词；平板 Rail（模拟宽屏）；纯白模式；逐字歌词。

## 4. 契约
新增（已冻结于 `core/contracts/V2Contracts.kt` 与扩展属性）：`DiscoverRepository`、`CommentRepository`、`ExternalPlaylistRepository`、`SubtitleRepository`、`UpdateRepository`、`DownloadRepository`、`BackupRepository`；`HistoryRepository` 增加 allHistory/ranking/historyByDay；`LyricsRepository` 增加逐曲 offset；`PreferencesRepository` 增加外观/歌词/下载/更新设置；`PlaybackController.setLyricLineProvider` 供通知歌词行使用。
实现方：data（Discover/Comments/Import/Subtitle/Update/Backup）、playback（Download/通知歌词行/淡出定时）、lyrics（SPL/逐曲 offset）、app（UI 与接线）。

## 5. 非目标 / 风险
- B 站评论接口匿名可用（已实测），但风控可能收紧；失败降级为提示。
- 网易云/QQ 歌单接口匿名可用（已实测），匹配限速 ~700ms/曲，歌单 30–100 首时导入耗时较长（显示进度）。
- 桌面歌词需要 `SYSTEM_ALERT_WINDOW` 权限（引导用户手动授予）。
- 下载文件为 m4s（ISOBMFF），导出到公共目录以 `.m4a` 命名并标注容器格式，部分播放器可能识别为 fragment MP4。
- 状态栏歌词以「媒体通知第二行」实现；第三方状态栏歌词模块（SuperLyric/Lyricon/魅族）明确不做。
