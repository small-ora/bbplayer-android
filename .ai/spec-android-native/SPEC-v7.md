# SPEC v7 — 播放页三页横滑（封面 / 歌词 / 评论）+ 歌词偏移只在设置里调

状态：实现前冻结（用户需求明确）。级别：**L2**（播放页 UI 重构 + 手势/导航行为；不涉鉴权/schema/依赖）。
基线：`0d502f8`（v0.6.0）。目标版本：随下一个版本发布（版本号待发布时定）。

## 1. 用户需求（原话）

> 目前有个新需求，就是把播放界面再优化一下。进去之后默认显示封面图，然后可以左滑切换到歌词界面，然后再左滑切换到评论界面。歌词界面不要有调整按钮，就是展示用的。如果要调整，就在菜单的设置里添加歌词的偏移调整。

## 2. 目标

播放页改成横向 3 页（封面 → 歌词 → 评论），默认封面；歌词页纯展示（去掉 ±0.1s 偏移按钮）；歌词偏移统一在「设置 → 歌词 → 歌词偏移」调整（已存在，保留并作为唯一入口）。

## 4. 非目标

- 不改数据层/契约/偏好键；不删除逐曲偏移的存储 API（仅移除播放页调整入口）。
- 不做上下滑/捏合手势；不改其它页面；不新增依赖（pager 用已有 foundation）。
- 不做评论发布（仍只读）。

## 5. 风险与实现要点

- `HorizontalPager`（foundation 1.10）与 `SeekLine` 的横向拖拽可能抢手势：SeekLine 在拖动时 `change.consume()`，预期子组件优先；真机重点验证。
- 评论页复用 `CommentsScreen` 内容（抽 `embedded` 模式，去掉返回栏），外层套不透明圆角卡片，保证阅读可读且与播放页视觉融合。
- 歌词页保留 `MiniTransport`（播放/上一首/下一首）与「点歌词 seek」；只去掉偏移调整按钮。
- 顶部栏居中加 3 点页码指示，提升可发现性。
- 歌词页可见时 `NowPlayingLyrics.inAppLyricsVisible = true`（桌面歌词自动隐藏），从 `showLyrics` 状态改为 pager 当前页。
