# SPEC v1 — BBPlayer 安卓原生版（Kotlin + Compose，椒盐音乐风格）

状态: 冻结基线（见 SPEC_BASE 文件）。级别: **L2/L3（高工作量新应用，无鉴权/密钥红线 → 按 L2+ 执行，SPEC 冻结后实现）**。
用户已拍板: ① Kotlin + Jetpack Compose + Material 3；② v1 = 核心可玩版；③ 不做 B站账号登录，匿名播放。

## 1. 目标
把 BBPlayer（Bilibili 音频播放器）的核心听歌体验用安卓原生语言重写为可安装、可日常使用的 App；视觉与组件风格对齐「椒盐音乐」（Salt Player）。

## 2. 非目标（v1 明确不做）
账号/Cookie/扫码登录 · B站收藏夹/合集/UP 主/稍后再看 · B站装扮皮肤引擎 · 下载与 m4a 导出 · 桌面歌词/状态栏歌词/车载歌词 · 播客字幕 · 评论 · 歌单导入（网易云/QQ） · 分享/云同步 · 平板两栏与导航栏 · 数据上报/分析 · 单元测试以外的 instrumentation 测试框架。

## 3. 可验证验收标准（AC）
每条 AC 的验证方式：`B`=构建命令、`U`=单元测试、`D`=真机 adb 操作+截图、`M`=人工查看截图。

### A. 工程与交付
- **A1** `./gradlew :app:assembleDebug` 退出码 0，产物 `app/build/outputs/apk/debug/app-debug.apk` 存在。(B)
- **A2** `./gradlew :app:testDebugUnitTest` 退出码 0，测试报告中用例数 ≥ 25 且 0 failure。(U)
- **A3** APK 可 `adb install -r` 安装并在设备冷启动进入首页，logcat 无 `FATAL EXCEPTION`。(D)

### B. 发现与搜索（首页）
- **B1** 首页展示「最近播放」横滑列表与「B站音乐区热门」列表（ranking rid=3），可下拉刷新；网络异常时显示错误提示与「重试」，不崩溃。(D/M)
- **B2** 搜索支持关键词、BV 号、AV 号、b23.tv 短链、完整视频链接，均可得到可播放结果。(D)
- **B3** 搜索结果含封面、标题、UP 主、时长、播放量；点击开始播放；搜索历史可记录与清空。(D/M)
- **B4** 单元测试覆盖 BV/AV/短链/URL 解析与搜索结果映射。(U)

### C. 播放
- **C1** 点击结果后播放页显示封面/标题/UP 主，播放进度推进，可暂停/继续/上一首/下一首。(D)
- **C2** 后台播放：按 Home 后音频继续，通知栏出现媒体通知（封面+播放/暂停/上一首/下一首），锁屏可控。(D)
- **C3** 播放模式：顺序/列表循环/单曲循环/随机，切换后行为正确且持久化。(U + D)
- **C4** 队列：查看、跳转、移除、清空；App 重启后恢复上次队列、曲目与进度（断点续播）。(D)
- **C5** 拖动进度条 seek 生效；倍速 0.5x–2.0x 生效。(D)
- **C6** 定时关闭：预设 15/30/45/60 分钟与自定义，倒计时结束暂停播放。(U + D)
- **C7** 音质：默认最高可用（30280），可在设置选择 64/128/192k；请求失败/无对应档位时回退到最高可用档，不崩溃。(U + D)
- **C8** 音频 URL 失效（403）时自动重新解析 playurl 并重试一次。(代码审查 + logcat 记录)

### D. 歌词
- **D1** LRC 解析支持：`[mm:ss.xx]`/`[mm:ss.xxx]`、一行多时间戳、`[offset:]`、纯文本行、空行过滤；单元测试覆盖。(U)
- **D2** 歌词自动获取：优先 QQ 音乐接口匹配（标题+UP 主清洗后检索），失败回退 B站字幕/提示；支持手动粘贴 LRC 并本地缓存；无歌词时显示空状态与入口。(D)
- **D3** 播放页歌词逐行高亮并自动滚动居中；点击歌词行 seek；当前行强调（放大/加粗/主色）。(D/M)
- **D4** 歌词偏移 ±0.5s 调整生效并持久化；字号可调（设置）。(U/D)
- **D5** 单元测试覆盖歌词匹配清洗、行合并、偏移应用。(U)

### E. 音乐库 / 收藏 / 统计
- **E1** 本地歌单：新建/重命名/删除；从搜索结果或播放页加入歌单；歌单详情播放全部、移除单曲；数据持久化（重启保留）。(D)
- **E2** 最近播放：自动记录并按时间倒序展示，可清空。(D)
- **E3** 本地点赞（红心）：播放页红心状态持久化，我的-收藏列表可播放。(D)
- **E4** 听歌统计：累计时长、播放次数、近 84 天热力格，基于真实历史。(U + M)

### F. 主题与设计（椒盐音乐风格）
- **F1** 使用 SaltUI 设计 token：背景 `#F3F3F3`/`#202020`、主色 `#0470E6`/`#0088FF`、subBackground 半透明卡片、8/16/24dp 圆角、12/16/24sp 字级；界面无 Material 默认紫色、无 elevation 阴影卡片。(M)
- **F2** 深浅色跟随系统/强制浅色/强制深色三态；Android 12+ 支持动态取色（Monet）并映射到 Salt 色彩角色；设置持久化。(D/M)
- **F3** 播放页：封面取色渐变/模糊背景、圆角封面、标题/UP 主、2dp 进度线（时间在下方）、裸图标控制行、底部功能行（循环/定时/音质/队列/歌词），整体观感对齐椒盐音乐。(M)
- **F4** 迷你播放条：位于底部导航上方，含封面/标题/播放暂停/队列入口，点击进入播放页；可在 3 个 tab 间保持。(D/M)
- **F5** 底部导航：首页/音乐库/我的 三 tab，图标无文字标签或轻标签，切换保留滚动位置；大标题页头。(D/M)
- **F6** 加载中骨架/空状态/错误态三态齐全，无白屏。(D/M)

### G. 设置 / 我的
- **G1** 设置项：主题模式、动态取色、默认音质、启动自动播放、断点续播、歌词字号、歌词偏移、清除缓存、关于/开源许可；均有持久化。(D)
- **G2** 清除缓存生效并显示释放大小；关于页含版本号、数据来源声明、BBPlayer(MIT)/SaltUI(LGPL-2.1) 归属。(M)
- **G3** 听歌统计页与设置入口在「我的」tab 可达。(D)

### H. 健壮性
- **H1** 断网时：首页/搜索显示可重试错误；播放失败提示；无崩溃。(D)
- **H2** 无 ANR：连续操作 15 分钟（切 tab、搜索、播放、歌词、队列、设置）无崩溃/ANR。(D + logcat)
- **H3** 不采集/不上传任何用户数据；无硬编码密钥。(代码审查)

## 4. 契约与依赖约束
- 只使用 `https://api.bilibili.com` 只读接口；匿名请求带桌面 UA + `Referer: https://www.bilibili.com/` + 启动时获取的 buvid3。
- 第三方歌词接口（QQ/网易云）只读、失败可降级。
- 新增依赖须在本 SPEC 记录；v1 锁定：SaltUI 2.8.6、Compose 1.10.0、media3 1.11.1、Coil 3.4.0、OkHttp 4.12、kotlinx.serialization 1.13、DataStore 1.1.7、Navigation 2.9.8。

## 5. 风险与人工门禁
- **门禁1（人）**: 前台 UI 观感是否符合“椒盐音乐风格”由用户验收（截图对比）。
- **门禁2（人）**: 若需上线分发，需用户确认 LGPL-2.1 依赖与 B站 接口合规；v1 仅本地安装。
- 技术风险：DASH `.m4s` 兼容、CDN 403、第三方歌词不可用、SaltUI API 学习成本。

## 6. AC 变更规则
实现开始后冻结；需变更时 SPEC 升级 v2 并列入验收包 old→new，由用户确认。
