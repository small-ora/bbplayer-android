# SPEC v5 — 登录体系（扫码 + Cookie）、收藏夹/合集/稍后再看/UP主、高音质、历史上报

状态：实现期冻结（用户已确认范围，见下「用户决策」）。级别：**L3**（鉴权/凭据红线）。
基线：v0.4.0。完成后发布 v0.5.0。

## 1. 用户决策（已确认）
- 登录方式：**扫码登录（主）+ 手动 Cookie 粘贴（备用）**；不做手机验证码（极验成本高）。
- 登录后能力：收藏夹、合集/系列、稍后再看、高音质（FLAC/杜比）、UP 主主页与关注、播放历史上报（默认关）。
- 凭据策略：**Android Keystore 派生密钥 AES-GCM 加密存本地；不打印、不上传第三方；退出即删除；网络请求只发往 bilibili.com**。

## 2. 目标
把 B 站账号体系引入，并在其上提供收藏夹/合集/稍后再看/UP 主/高音质；所有凭据相关行为可审计、可退出、可清除。

## 3. 可验证验收标准（AC）

### A. 登录与凭据安全
- A1 扫码登录：生成二维码 → 未扫码/已扫码/过期/成功四态正确；成功后导航栏显示头像昵称，重启 App 仍登录。
- A2 Cookie 粘贴登录：合法 Cookie 登录成功；非法/过期给出明确错误且不保存。
- A3 凭据存储：落盘文件/日志中不出现 SESSDATA/bili_jct 明文；加密存储（Keystore AES-GCM）；`adb logcat` 全量搜索无 Cookie 值。
- A4 退出登录：本地凭据被删除、界面回到未登录、收藏夹/合集等入口给出「请先登录」。
- A5 登录态请求：登录后接口请求携带 Cookie，`nav` 返回 isLogin=true；未登录请求不携带账号 Cookie。
- A6 缓存隔离：接口缓存 key 含登录身份，登录/未登录结果不混用；缓存 value 不含 Cookie。

### B. 内容能力（全部需登录）
- B1 收藏夹：列表（含默认收藏夹）、内容分页、播放、收藏/取消收藏视频、进入详情。
- B2 合集/系列：我的合集列表 + 内容播放。
- B3 稍后再看：列表、添加、移除、清空。
- B4 UP 主：信息（昵称/头像/签名/粉丝数）、视频列表分页、关注/取关（WBI 签名）。
- B5 播放页入口：收藏到收藏夹（多选）、加入稍后再看、进入 UP 主主页。

### C. 高音质与隐私
- C1 登录 + 设置开启高音质时优先 FLAC/Dolby（不可用时回退最高 AAC）；未登录/关闭时保持现状。
- C2 播放历史上报：默认关闭；开启且登录时上报进度（失败静默）；关闭时不发请求。
- C3 设置 → 账号显示登录状态与退出；隐私说明清晰。

### D. 质量
- D1 新增单测 ≥ 60（data：登录/加密/WBI/收藏/合集/稍后再看/UP主/选流/上报）。
- D2 全量门禁绿（v4 445 + v5 新增），assembleDebug/Release 通过；CI 发布 v0.5.0。
- D3 **独立安全审查**：fresh reviewer 只读审查 v5 diff（凭据存储/日志/缓存隔离/CSRF/越权/外发），P0/P1 处置。

## 4. 非目标
手机验证码登录（极验）、账号绑定/多账号切换、云同步、收藏夹批量管理增强、UP 主动态/直播、大会员购买等。

## 5. 风险
- 二维码接口/扫码状态码可能变化；失败提示清晰、可重试。
- WBI 签名随每日 key 轮换，key 失效需重取；签名错误时 UP 主接口失败但不影响其他功能。
- 凭据泄露风险由加密与日志策略控制；任何 Cookie 出现在日志视为 P0。
