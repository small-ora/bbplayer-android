状态：实现冻结（用户已明确「重复配置只保留最方便设置的一个，其余取消」）。级别：**L2**
（多文件 UI 配置重构 + 版本发布；不涉鉴权/schema/新依赖）。
基线：`59d5071`（v5 + 侧边栏导航/底栏播放条已合入 main）。目标版本：versionCode 7 / versionName 0.6.0。

## 1. 用户需求（原话）

> 提交，然后发布 V6 的版本吧，把一些配置项设置一下。有些重复的配置项就只保留一个最方便设置的就行了，其他的就可以取消掉。

## 2. 勘察结论：当前重复/重叠的配置入口（实测代码）

| # | 重复项 | 现状 | 保留（最方便） |
|---|---|---|---|
| D1 | 音质 | 设置→播放 同时有「音质」下拉（已含 杜比全景声 / Hi-Res 无损）**和**「高音质（登录后可用）」开关；两者都控制 FLAC/杜比偏好，语义重叠且下拉选项在没有开关时并不真正生效 | **只保留「音质」下拉**；选 杜比/无损 即开启高音质（未登录时提示并跳登录），选 AAC 档位即关闭；数据层 `highQualityAudio` 偏好继续写入（v5 逻辑不变） |
| D2 | 导入批量 | 设置→下载「导入每批匹配数」**与**导入页工具栏「每批 N 首」胶囊（同一偏好 `importBatchSize`） | **只保留导入页胶囊**（就在使用处、一点即切） |
| D3 | 我的页设置入口 | 「设置」**与**「主题与外观」两个条目都跳同一个设置页 | **只保留「设置」** |
| D4 | 启动行为 | 「启动时自动播放」+「断点续播」两个开关（前者只在后者开启时有意义） | **合并为「启动时」一项三选一**：关闭 / 恢复上次播放 / 恢复并播放（仍分别写 `resumeOnStart`/`autoplayOnStart`） |
| D5 | 缓存清理 | 设置→歌词「清除歌词缓存」**与**设置→缓存「清除接口缓存」两个清缓存入口 | **合并为缓存组一个「清除缓存」**（同时清接口缓存 + 歌词缓存），保留缓存用量展示 |

其它检查过但**不算重复、保持不动**：账号（设置页账号区 = v5 AC C3 要求；我的页账号卡 = v5 AC A1 要求）、迷你播放器样式（DOCK/FLOAT 语义不同）、歌词偏移（设置=全局；播放页=逐曲，作用域不同）、播放器背景/主题/动态取色/强调色（不同维度）、「已下载管理」等导航入口。

## 4. 非目标

- 不恢复本仓库当前缺失 UI 的其它偏好（逐字歌词/翻译/桌面歌词/状态栏歌词/自动检查更新）——记录为已知限制，不在本版处理。
- 不改数据层/契约/依赖；不改 v5 凭据/登录逻辑；不改侧边栏与底栏交互。
- 不删除任何偏好键（旧值继续生效，便于回滚与兼容旧备份）。

## 5. 风险

- 合并「音质/高音质」只动 UI 层写偏好，数据层选择逻辑不变；若登录态判断异常，回退为 v5 行为（开关值仍保留）。
- 版本发布需推送 tag 触发 CI；若网络/凭据失败，降级为本地 tag + APK 产物，并在验收包标注 BLOCKED 项。
