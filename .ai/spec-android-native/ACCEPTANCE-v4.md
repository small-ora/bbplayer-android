## 3. 真机验证

- 导入任务持久化：`shots/v4-01-import-resume-banner.png`（重启后 banner 与继续按钮存在）。
- 风控停止：命中 `-412` 时 UI 显示「请求被B站安全策略限制，请约 N 秒后重试」，任务保存为 PAUSED，不丢已匹配结果。
- 分批完成 + 吸顶保存：风控冷却结束后，30 首歌单按每批 20 首自动分 2 批完成（30/30，成功 30 · 未匹配 0），顶部吸顶栏直接「保存为本地歌单（30 首）」（`shots/v4-02-sticky-save.png`）。
- 歌词来源偏好/每批数量：设置页可切换并持久化（DataStore）。
- 风控属实存在：重测试期间命中 -412 后，等待冷却（约 1 分钟）再次点「继续匹配」即可恢复；本次已验证 30 首歌单分 2 批全部完成。若同 IP 短时间大量导入仍可能被拦截，建议分批。

## 4. 已知限制

1. 风控是服务端/IP 级：同 IP 短时间大量导入仍可能被拦截；建议单次 ≤100 首、分批导入、间隔一段时间。
2. 连续失败计数按「单次 matchBatch」重置；阈值前的普通失败记为未匹配并推进（续跑不自动重试这些曲目，可手动匹配替换）。
3. 旧缓存补字仅在线路径；手动粘贴歌词不估算（保持原文，逐字效果取决于文本是否带词级时间）。
4. 落盘失败会向上抛错（不静默），极端磁盘异常会中断导入；后续可改为写入 errorMessage。
5. 逐字仍为「真实数据优先 + 均匀估算兜底」；估算来源标记为 `:estimated`，UI 未单独展示徽标。

## 5. 需要你验收的 3 件事

1. 找一个**较少触发风控**的时间/网络，导入 30–50 首歌单：中途点「暂停匹配」→ 退出 App → 重进导入页 → 点「继续匹配」，确认从断点继续且不重复匹配。
2. 设置 → 歌词 → 把「歌词来源」切到「网易云优先」，清一次歌词缓存后播放一首歌，确认取词来自网易云（无逐字时也能看到逐字渐变，来源标记估算）。
3. 老歌（v3 之前已缓存歌词）直接进歌词页，应已自动出现逐字渐变，无需手动清缓存。
