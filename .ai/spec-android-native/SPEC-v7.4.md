# SPEC v7.4 — 首页模块化（最近播放歌单等）+ 菜单去掉搜索

状态：实现冻结。级别 L2。基线 `98fd971`（v0.7.3）。目标 versionCode 12 / 0.7.4。

## 需求（用户）
1. 首页新增「最近播放的歌单」栏目，展示歌单与相关信息。
2. B 站音乐区热门不要占满整页，补充其它模块。
3. 菜单（抽屉）去掉「搜索」，与首页搜索框重复。

## 实现
- `Playlist` 增加 `lastPlayedAt`（默认 0，JSON 向后兼容）；`LibraryRepository.markPlaylistPlayed(id)`；从音乐库播放歌单或歌单详情播放时记录。
- 首页模块：搜索框 → 最近播放（单曲，按 key 去重）→ 最近播放的歌单（2×2 封面拼图 / 名称 / N 首 · 最近播放）→（无记录时）我的歌单 → 我的收藏 → 收听统计 → B 站热门前 6 首 + 完整榜单。
- 抽屉/宽屏导航移除「搜索」（首页搜索框仍可进入搜索页；搜索页保留底部迷你播放器）。
