# SPEC — BBPlayer 移动端 UI/UX 重构：底部导航 + 悬浮迷你播放器

状态：实现冻结（v1）· 级别：**L2**（跨 10+ 文件、信息架构变更、含产品取舍）
基线 `c415b02` · 分支 `feat/ui-bottomnav-refresh` · 目标版本 0.7.5（versionCode 13）

## 1. 目标

按需求文档把「抽屉导航 + 底栏即播放条」改为「底部 3 Tab 导航 + 悬浮胶囊迷你播放器」，
并重排发现页 / 曲库页 / 我的页 / 全屏播放器，统一 Material You 视觉 token，提升现代感与精致度。

## 3. 非目标

- 不改数据层 / 播放逻辑 / 登录 / 下载 / 歌词解析；不新增依赖；不改版本号之外的发版流程。
- 不重做搜索页、详情页、设置页的内容信息架构（仅统一底部 padding；设置页删除已废弃的「迷你播放器样式」一项）。
- 宽屏（≥600dp）保留左侧常驻 NavRail（自适应），不强制底部导航；不做平板两级布局重构。
- 不改纯白墨水屏主题与动态取色开关行为（只调整浅色 neutral token）。
- 不做批量管理以外的批量操作（导入、下载等）。

## 4. 假设与取舍（人可推翻）

1. **「识别」FAB 不存在**：当前原生版没有识别入口，需求第 3 条的后半句按「无纯色 FAB + 功能收敛顶栏」验收。
2. **批量管理**：仓库没有现成批量管理，按最小可用实现为歌单多选 + 批量删除（曲库页内）。
3. **MiniPlayerStyle 设置废弃**：新规范固定为悬浮胶囊，删除设置页「迷你播放器」样式项；`MiniPlayerStyle`
   枚举保留（数据兼容），UI 不再读取。
4. **底部安全区数值**：需求「约 140dp」= 导航 80 + 迷你 64 - 4；本实现根页取 156dp、二级页取 140dp，
   保证最后一项不被遮挡，且与需求数量级一致。
5. **搜索页**从发现页搜索栏进入，属二级页（底栏隐藏、迷你播放器贴底）。
6. 折叠屏/旋转：只保证手机竖屏主场景；横屏不专门优化。

## 5. 契约 / 风险 / 人工门禁

- 契约：不动 `core` 契约；`AppRoot` 路由常量保持既有字符串，新增路由仅内部使用。
- 风险：dynamic color 覆盖影响其他主题 → 4 主题截图回归；inset 双计 → 统一外层管理。
- 人工门禁：视觉与交互品味由人验收；本任务不 push / 不合入。

SettingsScreen 删一项）。不改其余模块。
